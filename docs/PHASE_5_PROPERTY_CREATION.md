# Phase 5 — recoverable property creation and reviewed templates

September 22, 2026. Locally verified; Phase 5 remains active.

Property creation within an existing organization now saves the property, selected copied details, the nine setup tasks and attributed creation evidence in one transaction. A lost response keeps the same request identity. Reloading the wizard can recover the saved property and its current details; it cannot silently fall through into creating a duplicate. Only the opaque request identity is retained in session storage. Finishing setup saves the reviewed facts, retained contact identities and connection plans atomically against the version the operator loaded. Only the actual details/contact tasks are completed. A conflicting change holds the draft; the operator can inspect saved history or explicitly discard the draft and resume the saved version.

Template copying now checks current manager and organization access and requires review of the exact selected source values. Contacts receive new target identities while the private receipt retains the source snapshot. Service copying includes platform intentions only; no account identifiers, credentials or verified status are copied. Optional voice, audience and policy guidance must be explicitly confirmed as applicable. If the source changes, creation waits for a new review. Reloaded recovery reads the saved target instead of silently recopying its source. Zero counts and city-only addresses are retained; creation does not guess a timezone or launch a website import.

Private creation and setup history retains the original request, accepted template, actor, source hashes and before/after details. Shared `property.created` and `property.onboarding.completed` records contain safe identities and hashes rather than private contact text. Old unversioned create/edit adapters are retired. The unused exported quick-add modal now routes into the complete guided flow; repository caller review found no mounted quick-add caller. Actual connection authorization remains a separate operation. Setup completion is a data-entry milestone, not a declaration that the property or every product is ready for clients.
