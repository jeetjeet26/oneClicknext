# Phase 5 — SiteForge delivery records and evidence review

September 22, 2026. Locally verified; Phase 5 remains active.

SiteForge now retains a supplied delivery report as an exact private source, with its original text/name, reported target and source revision, import actor/date, optional observation date, content/editor ownership and a same-property saved brief. Markdown and plain-text files are bounded to 256 KiB and must be valid UTF-8; Unicode, BOM and line endings are preserved. Source text is inert, not rendered or executed. Import does not read a URL, inspect a client project or verify a deployment. Revised reports create new records with parent ancestry and preserve the original.

Operators review eleven delivery categories: design/routes, editing, previews/revisions, facts/inventory, inquiries/integrations, accessibility/content, imports/redirects, package/runtime, domain/discovery, recovery and maintenance. Every category has an explicit reported status. Reported passes require dated evidence and a named source revision. Failed, blocked and out-of-scope checks require explanations. The full review commits atomically with its reason, actor, exact source hash and expected prior review. Concurrent stale reviews cannot overwrite a newer decision; corrections and withdrawals remain in the history. Withdrawal does not revive earlier passing evidence. A revised source starts without inherited passes.

Lost replies reuse stable request identities. Complete record and review paging extends beyond the REST row cap. Failed reads remain visible and delayed responses are fenced on property changes. Original reports, optional brief and parent links, review decisions and withdrawn history can be reopened after reload. Shared action records contain safe identities and hashes, while raw reports and evidence remain private. The new actions are `site.delivery.recorded`, `site.delivery.reviewed` and `site.delivery.withdrawn`; their server confirmation establishes retained decisions, not live website delivery. No overall client-ready or autonomy-ready result is inferred.
