## What is now implemented

The application has a **Community knowledge** workspace with community-scoped originals, source/asset review, exact floorplan retrieval, private downloads and ZIP bundles, connected Drive/Dropbox intake and schedules, versioned initiatives/service packages, permissions, processing status, historical replay and administrator activation controls. The internal portfolio assistant reads an explicit authorized selection; its conversations and exports remain separate from each community's knowledge.

The shared context contains current structured facts, inventory and brand; selected eligible assets; and bounded eligible lexical/vector evidence. SiteForge, ForgeStudio, BrandForge and the public chatbot consume scoped context. Generated creative becomes style memory rather than factual authority. A competitor capture is internal research describing that competitor; it cannot establish the owner's amenities. Source withdrawal, rights expiry, permission changes and rollout changes invalidate eligibility before asynchronous indexing finishes.

Originals live in private Storage with immutable keys and SHA-256 identities. Search stores derived text and provenance, not binary image files. Exact assets and drawings are selected by ID and page. A restricted worker receives leased work and uses a network-disabled parser process without database or model credentials. Worker Auth and Storage permissions were exercised using actual local HTTP services.

New features default to **off per community**. Administrator activation separates generation consumers, new intake, private downloads, portfolio access and approved creative feedback. Activation grants no publication or spending authority. Manage/research access remains available to prepare sources while consumer generation is paused.
