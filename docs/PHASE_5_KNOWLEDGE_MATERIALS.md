# Phase 5 — reviewed text knowledge lifecycle

September 22, 2026. Locally verified; Phase 5 remains active.

Plain text now has a complete recorded path: retain the exact private original, correct it as a new immutable version, explicitly prepare search data once, retain and validate the model receipt, then separately publish, replace, withdraw or deliberately republish an exact reviewed version. Text and UTF-8 .txt/.md input up to 256 KiB preserve short passages, CRLF, BOM and Unicode. Search chunks retain the entire original and never cut a Unicode character or exceed 4,096 UTF-8 bytes. Saved drafts do not replace an existing publication.

Preparation saves the source version, input hash, exact chunks and fixed model recipe before a single claim can run. Execution respects the outbound pause and configuration checks before claiming; the canonical OpenAI embedding call has no SDK retry. Received output, provider receipt and reported usage are retained privately before validation. Billed cost is explicitly unavailable. Malformed output, missing or repeated indices, wrong dimensions/model, zero vectors and uncertain outcomes cannot become publishable data. Retrying receipt persistence reuses the same receipt, never invokes the model again. Stopping an in-flight request retains any late receipt without reviving publication. Local receipt validation works while outbound calls are paused. Job success means search data was prepared, not that the source was published or the client product accepted.

Publication rechecks the current manager, organization, exact source version, active publication, last release decision and retained valid receipt in one database transaction. Only this material's managed vector chunks are replaced or withdrawn. Unrelated legacy imports remain intact. Source status and active pointers change with the recorded decision; saved assistant facts become stale without losing their text or prior review requirement. Publication does not regenerate Luma's facts. Managed chunks, source records, original versions, private decisions, model inputs, receipts and shared context identity are protected against generic writers. The old metadata-arbitrary ingestion and shared-label deletion routes are retired. The paste compatibility route uses the strict recorded decision contract rather than an immediate embedding path.

The review workbench supports complete paged source/version/decision history, exact originals addressable by URL, stale-version rejection, property isolation, unavailable reads, explicit stop/recovery, and saved-response recovery after browser reload. Browser storage holds request identifiers and a digest, not the source text. An unused request can be cancelled transactionally: an already saved decision is recovered instead, and a delayed copy of a cancelled request cannot save later. Human decisions and system preparation outcomes have distinct attribution; shared activity contains IDs/hashes instead of the raw source. No records become training-eligible automatically.
