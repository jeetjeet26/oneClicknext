# PropertyAudit recorded decisions — local qualification

September 23, 2026. This qualifies audit controls and durable measurement/crawl evidence locally; the full PropertyAudit and Phase 5 gates remain open.

Operators can review and save exact questions, edit or activate them with stale-edit protection, archive them and restore them inactive. Templates and CSV proposals remain editable before saving. Every saved choice retains its actor, source, before/after state and an immutable private receipt. Interrupted requests recover their saved result; cancelling an unused request fences late submissions. Shared history contains safe identities and remains training-ineligible.

Run requests capture the reviewed questions, models, repeat count and explicit website-crawl choice. Stop, linked retry, archive, restore and evidence review retain original measurements. Worker history is separately attributed. Actual provider responses are retained before application; a late response after stopping cannot silently complete a run. Current-role withdrawal prevents new provider execution. Website crawls have bounded leases, page persistence, coverage and linked retry. Missing findings are not automatically called fixed; staff-reported fixes are not verified improvements.

Complete paged question/run/finding/recommendation/history inventories and private response inspection are available. Performance for current questions uses matching captured wording; unmeasured questions stay unmeasured. Synthetic fixtures are labelled and excluded from background execution.
