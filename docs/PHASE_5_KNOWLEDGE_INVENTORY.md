# Phase 5 — complete knowledge inventory and side-effect-free reads

September 22, 2026. Locally verified; Phase 5 remains active.

Knowledge inventory now reads complete property-scoped source, material-group, text-chunk and floorplan counts in the database, rather than counting capped REST results or silently treating a failed count as zero. The community overview shows unavailable knowledge reads explicitly. Source records and stored material are separate collections; recorded source chunk totals are labeled as reports instead of being substituted for actual stored counts. Source statuses, errors, historical sync times and reported provenance remain visible. The inventory is private and rechecks current actor/organization scope on every page.

Stored material prefers the recorded ingestion-run identity, then a reported source identity. Older material falls back to an explicitly labeled grouping by source label and title; unclassified chunks remain individual records. Distinct pasted imports no longer collapse into a single generic pasted_text entry. This grouping is not a claim that an original file was retained or reconstructed. Sources, groups and exact stored chunk previews have full paging; content beyond 10,000 characters is explicitly marked as a truncated preview. Selected groups can be reopened by URL. Continuation checks the complete inventory version, including content changes without timestamps, and holds paging when that version changes. Failed reads and property changes cannot show an empty success or material from another property.

Floorplan GET no longer launches knowledge synchronization or embedding. Its existing compatibility consumer receives complete floorplans up to 2,000 entries, with an explicit oversized-collection response beyond that bound; the native read supports subsequent bounded pages. Opening community brand notes no longer creates an import preview automatically. It reads previously saved notes, labels source freshness as unchecked and offers the existing reviewed BrandForge flow. Reading the new inventory does not invoke a model, mutate source content or claim a user decision. This is not semantic action coverage for the still-unfinished knowledge mutation lifecycle.
