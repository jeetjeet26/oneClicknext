Response text is an immutable saved version with its exact review source, property facts, current analysis, model/prompt/policy contract and content hash. Editing preserves history, explicitly replaces pending drafts and cancels their prior execution permission. Approval/rejection uses current manager access and exact versions; a changed review or property context requires a new reviewed draft. A saved command identity recovers lost responses. The old ad hoc response endpoint and direct generation wrapper are retired; the remaining response dialog shares the same saved workflow.

Generation saves its context before one bounded model invocation. Private raw output persists before validation or draft application. Only identical receipt persistence is retried. Result recovery uses the saved output without another model; invalid facts, malformed output, refusals, old parser contracts, prohibited response text and changed source/context stay held. Stopped late results remain private evidence. Generated text never becomes an approval. Shared events distinguish human requests from workflow results; raw review/response narrative stays outside the general activity stream.

Manual publication is a separate, versioned handoff of approved text and a reviewed public destination. It blocks text replacement until staff reports the outcome, confirms that it was not published, or records uncertainty. Reports preserve the exact text, destination, time, actual reporting operator and evidence link. They are explicitly staff-reported, never provider-verified. An uncertain handoff cannot silently authorize another write. Publication does not resolve the staff case. If the review changes after a handoff, the historical report stays attached to the old source and the new review remains pending. Closed publication proof is immutable.

The drawer now offers saved generation history, draft history, response approval/rejection and publication evidence with bounded history paging, visible read failures and stable retry controls. The response button opens this saved workspace. A delayed drawer refresh previously hid newer case validation errors; the case panel now ignores redundant older refreshes and preserves pending decisions/errors. A browser regression delays the parent read and waits for its visible application before checking error preservation.
