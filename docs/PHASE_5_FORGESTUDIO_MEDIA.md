# Phase 5 — ForgeStudio durable media generation

Local checkpoint, September 17, 2026. Phase 5 remains active.

## Completed local behavior

Media requests now have stable user command identities, exact private input/model/source snapshots and one recorded model intent. The worker honors OUTBOUND_DELIVERY_PAUSED before claim and before intent. Preparation can recover an expired lease with a new token; a recorded model intent cannot be replayed. SDK retries are disabled for image, iterative image and video. One bounded invocation fits the route runtime. Cost estimates retain their request ceiling; actual provider billing is not asserted.

A generated file is inspected and its exact byte hash, length, type and dimensions are saved before immutable private storage. Recovery verifies those bytes, copies them to the managed library location and atomically saves the pending-review asset, private completion receipt and shared completion event. Lost storage/database replies never trigger another model invocation. A request with no confirmed result remains held. A late result after stop is retained privately and cannot become a library asset. Stop does not claim provider cancellation or avoided charges.

The library now exposes paginated saved media requests, reloadable read errors, saved instructions, recorded stop/recovery reasons and stale-decision handling. Later-page decisions retain their selected row. The generator uses the approved asset picker and the existing advisory rights policy. Source approval and file identity are checked again immediately before model intent. Current property/actor access is checked before result promotion. Earlier unqualified media jobs remain labeled legacy and cannot be replayed automatically.

Semantic actions: studio.media.requested, studio.media.stopped and studio.media.recovered commit with their decisions. studio.media.completed commits with the generated asset and carries workflow origin, requested-by and saved-by identities. Private worker intent/result/failure receipts remain separate evidence. Generated original file identity is immutable; archive/replacement remains available through the managed asset library.

## Remaining gates

Actual model/provider contracts, billing, provider-side cancellation and asynchronous provider-operation retrieval require later acceptance. A process that loses generated bytes before private storage cannot recover them from this local evidence alone; the request remains held without model replay. A stop racing a library storage copy can leave an unused stored object, but cannot save a library asset afterward. Legacy remote source URLs do not prove immutable remote bytes. No real model/provider calls, sends, deployment, hosted writes, training or migration-history writes occurred.
