# Phase 5 — ForgeStudio saved generation requests

September 17, 2026. Durable text-generation request/result recovery is locally qualified. Complete ForgeStudio and Phase 5 remain open.

A generation request is now saved against a real, scoped brief before retrieval begins. Its immutable brief snapshot, unique claim, exact context/model input and model-invocation intent precede the model call. An existing request returns its saved status without another retrieval or model run. One active request per brief prevents overlapping generation; completed briefs return their existing work. A lost intent response cannot authorize another invocation. AI SDK generation and context-retrieval embedding retries are disabled, and all verification uses injected models or saved fixtures.

Valid structured model output and returned usage/provenance are saved before domain claim validation and package materialization. Recovering that result uses the saved context and output; it does not contact a model or rerun retrieval. Package, immutable revision/variants, brief completion and generation completion save together. Failed package/history persistence leaves the raw result recoverable. Unsupported claims remain blocked. A malformed or missing model response remains uncertain rather than being silently retried.

The operator can stop a request with its opened version and rationale. A late result remains in private history and cannot reverse that stop or silently create a campaign. The UI explicitly distinguishes stopping local application from confirmed provider cancellation or cost reversal. Starting another model run is a separate explicit action. Generation start, stop and manual recovery record semantic decisions atomically; internal model/context/result receipts distinguish worker/model origin and remain private, with no training enabled.

The campaign workspace lists paginated saved requests with explicit reload errors, status, recovery, stop and open-draft controls. Interrupted browser responses recover the original result/decision. Request identities persist without storing private brief text in browser storage. Brief account loading failures now show a recovery path instead of falsely reporting no connected accounts.
