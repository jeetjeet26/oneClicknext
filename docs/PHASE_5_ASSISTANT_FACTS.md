# Phase 5 — reviewed assistant facts

September 22, 2026. Locally verified; Phase 5 remains active.

Luma now has a complete recorded path from current property knowledge to a reviewed facts publication. Preparing a draft retains the complete source snapshot, including supported public property facts, every matching-organization unit with its eligibility, every source reference and every exact retained document. The earlier renderer omitted ordinary source text and inspected only capped excerpts. The new deterministic draft includes it with source identities. Internal contacts, billing and credentials are excluded. Legacy material is labeled as such; it does not acquire reviewed-source status from arbitrary metadata.

Preparation and manual correction create immutable private versions. They never replace the active publication. Publishing, reconfirming and withdrawing require the exact current draft, source snapshot, context and publication pointers, current management access and an explicit decision. Publication commits its text, source identity, legacy context revision, private before/after evidence and safe shared action together. Withdrawal keeps history without falling back to an older version. Full version/decision history remains accessible beyond 1,000 records, and a specific version can be opened by URL.

Source collection and draft size are bounded at 5 MiB; publication is bounded at 64 KiB of UTF-8. Oversized drafts remain inspectable and cannot be silently truncated into a publication. An operator can save a deliberately shorter reviewed revision retaining the complete source evidence. Preparation and publication use no language model.

The Luma loader checks the adopted publication against current source content, property scope, exact saved context and freshness before returning facts. Changed or removed source text, publication withdrawal, review requirements, expired publication or stale website evidence withhold the facts. Legacy serving remains explicitly identified before first adoption. After adoption, generic writers cannot overwrite the reviewed context or clear its review requirement. Existing source/property invalidations can mark it stale while preserving its evidence. Each new request checks the source snapshot; this does not retroactively stop an answer already in progress.

The review screen shows source counts, eligibility, exact text/source evidence, manual drafts, current publication status and full history. It recovers a lost save reply after reload, keeps only identifiers/digests in browser storage and can cancel an unused request so a delayed copy cannot later save. Current-property changes and unavailable reads clear private views. Human facts decisions are recorded separately from model jobs and do not become training eligible.
